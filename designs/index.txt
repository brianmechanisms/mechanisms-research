// The cross-section is the union of four corner pieces (with rounded
// outer edge, face L-walls with V-slot inner lips, inner block, and a
// 45° V-back slab) plus a centre block carrying the M5 bore.

$fa = 1.0;
$fs = 0.4;

length = 200;

// Centre block (placed at the cell centre).
module center(l=1,r=1,t=1,b=1){
  difference(){
    translate([-3.9,-3.9,0]) square(7.8);
    circle(r=2.3);
    if(t==1) translate([0,3.688,0])  rotate([0,0,45]) square(0.3);
    if(b==1) translate([0,-4.112,0]) rotate([0,0,45]) square(0.3);
    if(r==1) translate([3.9,-0.212,0]) rotate([0,0,45]) square(0.3);
    if(l==1) translate([-3.9,-0.212,0]) rotate([0,0,45]) square(0.3);
  }
}

// One corner of the rail (bottom-left orientation).
module corner(){
  translate([0.5,0.5,0]) circle(r=0.5);
  // Bottom-leg L: hull of a flat and a lip → V-slot inner lip.
  hull(){
    translate([0.5,0,0])     square([4.92, 1.8]);
    translate([0.5,1.455,0]) square([6.375, 0.345]);
  }
  // Left-leg L (rotated copy of the above).
  hull(){
    translate([0,0.5,0])     square([1.8, 4.92]);
    translate([1.455,0.5,0]) square([0.345, 6.375]);
  }
  // Inner block.
  translate([1.8,1.8,0]) square(2.7);
  // 45° V-back slab.
  translate([4.5,3.44,0]) rotate([0,0,45]) square([3.763, 1.5]);
}

module v_slot_2020(L = length){
  linear_extrude(height = L){
    corner();
    translate([20, 0,0]) rotate([0,0,90])  corner();
    translate([20,20,0]) rotate([0,0,180]) corner();
    translate([ 0,20,0]) rotate([0,0,270]) corner();
    translate([10,10,0]) center();
  }
}

  hull() {

9:T8c5,Mechanism 70.3 (rod variant) — kinematic equations & key dimensions

KINEMATICS  (from Mechanism70c, world units; multiply X by worldScale to get mm)

  • Each slider follows S_i(t)·x = cam-driven trajectory of the ith carriage.
  • S1 and S3 are antiphase (180° apart). S2 and S4 are antiphase.
  • The two raised ridges on the cam are the polar pitch curves:

        ridge_k : r_k(θ) = | x_S_k(θ / (2π))  -  camAxisX |

    where x_S_k is the i-th slider's X coordinate, sampled around the
    cam rotation θ ∈ [0, 2π). The class method
    Mechanism70c.computeCamProfile('S1' | 'S2', N) returns the sampled
    {θ, r} pairs for each ridge.

  • cam axis X     = max(x_S2) + r2min        (from class.getCamAxisX)
  • Φ(t)           = 2π · t                   (cam rotation)
  • slider X (mm)  = (x_S_i(t) - camAxisX) · worldScale

RIDGE GEOMETRY  (the inverse of the v-slot variant's cut groove)

  • Ridge centreline = pitch curve.
  • Ridge cross-section: rectangular, thickness ridgeT (radial) × height ridgeH (along shaft).
  • Follower: a pair of rollers (radius rollerR · worldScale) on either side of the ridge.
  • Required follower-pair gap (centre-to-centre):
        rollerPairGap = ridgeT + 2·(rollerR · worldScale) + clearance

KEY DIMENSIONS (defaults)

  rod radius              rodR              = 8 mm
  rod length              rodLength         = 600 mm
  shaft diameter          shaftDia          = 8 mm  (608ZZ bore)
  shaft length            shaftLength       = frameDepth + 60 mm
  cam plate thickness     camPlateThickness = 6 mm
  cam plate outer dia     camPlateOuterDia  = 80 mm
  ridge radial t          ridgeT            = 4 mm
  ridge height            ridgeH            = 8 mm
  world scale          = 200 mm/unit
  L1 (world)           = 0.7
  L2 (world)           = 1.2
  parW (world)         = 0.08
  rollerR (world)      = 0.06   →  1.2 mm × worldScale (= 12 mm) … see notes
  r2min (world)        = 0.2

SLIDER WHEEL LAYOUT (3-wheel preloaded triangle)

  • Two grooved wheels on +Y side of the rod, spaced wheelSpacingX along rail axis.
  • One grooved wheel on −Y side at the carriage centre.
  • Wheel groove inner radius ≈ rodR + 0.5 mm clearance.
