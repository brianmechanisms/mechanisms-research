Mechanism Overview

Self-Powered Long Range Linear Motion

1DOF locomotion via sequential gripping - no rack or teeth required.

Elliptical Trammel Mechanism:
  • Point A (foot) - moves in X and Y (the locus we define)
  • Point B - slides on horizontal guide (X only, fixed Y)
  • Link AB - rigid bar of length L
A accounts for all Y movement.
Constraint |AB| = L determines Bx:
Bx = Ax ± √(L² - (Ay - By)²)
Walking Gait Phases:
  • STANCE: Foot on ground, pushing body forward
  • LIFT: Foot rises off ground
  • SWING: Foot in air, moving backward (relative)
  • DROP: Foot descends to ground
Net displacement = 0 over full cycle.
Vreturn auto-calculated for this constraint.

Phase Layout & Formulas

Cycle order: STANCE → LIFT → SWING → DROP → (repeat)
Vx (horizontal velocity):
  • STANCE: Vx = Vforward (constant)
  • LIFT: Early part has Vx = Vforward
  • Then Trans1: Vforward → Vreturn
  • SWING: Vx = Vreturn (constant, negative)
  • DROP: Trans2: Vreturn → Vforward
  • Then late part has Vx = Vforward
Overlap: % of Lift/Drop where Vx = Vforward
Transition curves:
Quintic: h(s) = 10s³ - 15s⁴ + 6s⁵
Sine: h(s) = (sin(πs - π/2) + 1) / 2
Vy (vertical velocity):
  • STANCE: Vy = 0
  • LIFT: Vy = Vy,amp · 16s²(1-s)²
  • Peaks at s=0.5, foot rises
  • SWING: Vy = 0
  • DROP: Vy = -Vy,amp · 16s²(1-s)²
  • Peaks at s=0.5, foot descends
Symmetric curve: 16s²(1-s)²
∫₀¹ = 8/15, peaks at s=0.5 with value 1
Red dashed lines = Vx transition boundaries
Vx = Vforward spans: late DROP → STANCE → early LIFT
Vreturn is auto-calculated so net displacement = 0 over full cycle.
