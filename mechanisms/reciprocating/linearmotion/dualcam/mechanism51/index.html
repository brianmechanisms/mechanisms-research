Displacement Calculation with Smooth Transitions

Smooth Transition Function

We use a quintic polynomial that ensures zero velocity derivatives at boundaries:

smoothTransition(t) = 6t⁵ - 15t⁴ + 10t³, where t ∈ [0, 1]

At t=0: smoothTransition(0) = 0
At t=1: smoothTransition(1) = 1
Derivatives at t=0 and t=1 are zero (smooth connection)

Velocity During Transition

When transitioning from velocity v₁ to v₂ over angle θ:

t = (angle - startAngle) / θ
velocity(t) = v₁ + smoothTransition(t) × (v₂ - v₁)

The parameter t is normalized: at start of transition t=0, at end t=1

Integration to Find Displacement

Displacement during transition:

displacement = ∫ velocity d(angle)

Since angle = startAngle + θ×t, we have d(angle) = θ dt

= θ × ∫₀¹ [v₁ + (6t⁵ - 15t⁴ + 10t³)(v₂ - v₁)] dt

= θ × [v₁×t + (t⁶ - 3t⁵ + 2.5t⁴)(v₂ - v₁)]₀¹

= θ × [v₁ + (1 - 3 + 2.5)(v₂ - v₁)]

= θ × [v₁ + 0.5(v₂ - v₁)]

= θ × (v₁ + v₂)/2

Result: Displacement = average velocity × angle

Total Displacement Equation

For a complete cycle (360°), total displacement must equal zero:

Forward section: forwardVx × forwardAngle
Transition 1: (forwardVx + returnVx)/2 × transitionAngle
Return section: returnVx × returnAngle
Transition 2: (returnVx + forwardVx)/2 × transitionAngle

Total = 0:
forwardVx × forwardAngle + (forwardVx + returnVx) × transitionAngle + returnVx × returnAngle = 0

Simplifying:
forwardVx × (forwardAngle + transitionAngle) + returnVx × (returnAngle + transitionAngle) = 0

returnVx = -forwardVx × (forwardAngle + transitionAngle) / (returnAngle + transitionAngle)

Example Calculation

With forwardVx = 1.0, forwardAngle = 180°, swingAngle = 180°, transitionAngle = 30°:

returnAngle = swingAngle - 2×transitionAngle = 180 - 60 = 120°

returnVx = -1.0 × (180 + 30) / (120 + 30)
returnVx = -210 / 150
returnVx = -1.4
