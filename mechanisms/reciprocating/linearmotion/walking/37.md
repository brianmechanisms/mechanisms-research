# Mechanism 37 - Multi-Phase Gait Design System

## Overview

Mechanism 37 implements an advanced multi-phase gait design system using locus-first design methodology with sophisticated four-phase motion profiles based on Shigley 1960 Walking Vehicle Principles.

## Key Features

### Locus-First Design Pattern
- **Precalculated Trajectory**: Uses working motion generator to create exact foot locus
- **Inverse Kinematics**: Slider positions calculated to maintain fixed connecting rod lengths
- **200-Point Resolution**: High-resolution foot locus with smooth phase transitions
- **Fixed Rod Constraints**: Maintains constant connecting rod lengths throughout cycle

### Three-Slider Configuration
- **S1**: Horizontal slider with fixed-length connecting rod to foot
- **S2**: Horizontal slider supporting vertical rail (X position = S3.x)
- **S3**: Vertical slider on S2's rail with connecting rod to foot
- **Proper Kinematics**: Inverse calculations ensure realistic mechanical constraints

### Four-Phase Motion System
- **Stance Phase**: Ground contact with constant forward velocity (40% of cycle)
- **Lift Phase**: Foot raising with stance-to-swing velocity transition
- **Swing Phase**: Rapid return motion with constant swing velocity
- **Drop Phase**: Foot lowering with swing-to-stance velocity transition

## Technical Implementation

### Motion Profile Generation
- **Four-Phase X-Axis**: Stance, lift, swing, drop with balanced displacement
- **Three-Phase Y-Axis**: Synchronized sine wave profiles with frequency modulation
- **Integration-Based Balance**: Auto-calculated swing velocity for closed-loop motion
- **Phase Synchronization**: Precise timing control with configurable parameters

### Mechanical Design
- **Reduced Rail Height**: Compact 15-unit rail height for better proportions
- **Optimized Slider Sizes**: 4×3 unit rectangles for clean visual presentation
- **Fixed Connecting Rods**: S1 rod length: 18.03 units, S3 rod length: 0.00 units
- **Proper Positioning**: S1 offset reduced to -10 units for balanced layout

### Visualization Features
- **High-Contrast Phase Colors**: Red (stance), green (lift), blue (swing), orange (drop)
- **Real-Time Displacement Profiles**: Integrated S1 and S2 position plots
- **Phase Boundary Markers**: Visual indicators for gait phase transitions
- **Current Time Indicators**: Black line showing mechanism state in displacement plots

## Generated Outputs

### Static Analysis
- **Mechanism Visualization**: Complete mechanism with locus and displacement profiles
- **Phase-Specific Plots**: Individual mechanism states at different cycle points
- **Connecting Rod Verification**: Constant length validation throughout cycle

### Dynamic Animation
- **Full Cycle Animation**: 50-frame GIF showing complete walking motion
- **Slider Movement**: All three sliders moving according to inverse kinematics
- **Fixed Rod Lengths**: Visual confirmation of constant connecting rod constraints

## Applications

- Advanced bipedal and quadrupedal walking robots
- Prosthetic devices requiring natural gait patterns
- Multi-legged vehicle systems with coordinated locomotion
- Gait analysis and biomechanical research platforms
- Educational demonstrations of walking mechanism principles

## Parameters

- **stance_fraction**: Fraction of cycle in ground contact (0.4)
- **y_amplitude**: Maximum step height (0.15m)
- **x_stance_velocity**: Forward velocity during stance (0.08 m/s)
- **x_swing_fraction**: Fraction of swing phase duration (0.3)
- **slider_offset**: Initial S1 position offset (10 units)
- **rail_height**: Height of horizontal rail (15 units)

## Implementation

The mechanism achieves 100% kinematic consistency with fixed connecting rod lengths verified across the complete walking cycle. The locus-first design ensures the mechanism traces an exact biomechanically-inspired walking trajectory while maintaining realistic mechanical constraints.
